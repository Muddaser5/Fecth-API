FETCH API PROJECT

# Description

This project demonstrates how to fetch and display data from an external API using JavaScript.
The application retrieves data from the DummyJSON API and shows it on a web page.

# Technologies Used

- HTML
- Tailwind CSS
- JavaScript
- Fetch API

# API Used

Data is fetched from the following API:

https://dummyjson.com/

# Project Structure

project-folder
│
├── index.html
├── readme.md
└── script.js

# How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in your browser.
4. The application will fetch and display data from the API.

# Purpose

This project is created to practice working with Fetch API and external APIs using JavaScript.
